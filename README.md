# Valeo Cognex Measurement Analysis

Short description

This project captures measurements from a Cognex vision system, computes basic statistics (mean, std, CV), derives 3‑sigma tolerances, and generates plots for inspection and analysis.

Files

- [cognex_script.py](cognex_script.py#L1) — acquisition: connects to Cognex, reads cells, writes `GOOD_parts.csv`.
- [limits.py](limits.py#L1) — computes 3σ tolerance limits and saves `tolerance_limits.csv`.
- [statistical_analysis.py](statistical_analysis.py#L1) — full analysis: summary stats, CV, Gaussian plots, saves `summary_statistics.csv` and `statistical_tolerances.csv` and per-feature plots in the `plots/` directory.
- [plot_std.py](plot_std.py#L1) — simple plot of standard deviations for blob features from `tolerance_limits.csv`.
- `GOOD_parts.csv`, `summary_statistics.csv`, `statistical_tolerances.csv`, `tolerance_limits.csv` — CSV outputs generated by the scripts.

Requirements

- Python 3.8+
- Packages: `pandas`, `numpy`, `matplotlib`

Install with:

```bash
pip install pandas numpy matplotlib
```

Quick usage

1. Capture measurements (ensure Cognex is reachable on the network):

```bash
python cognex_script.py
```

2. Produce tolerance limits:

```bash
python limits.py
```

3. Run statistical analysis and generate plots:

```bash
python statistical_analysis.py
```

4. Plot standard deviations for blob features:

```bash
python plot_std.py
```

Notes

- Cognex connection parameters are defined in `cognex_script.py` (variables `IP` and `PORT`). Edit them if your device uses a different address/port.
- `cognex_script.py` opens a TCP connection to the device and will attempt to log in with username `admin` and no password; run it only on a trusted network.
- Data and plots are written to the workspace folder; `statistical_analysis.py` creates a `plots/` directory for per-feature PNGs.
